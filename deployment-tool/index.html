Install a new VM

  1. Pick the disk. The target must be booted from the NixOS installer.
    DiskSizeModel
  2. Install (make init). Wipes the disk.
  3. Set passwords (make set-password) after the reboot, root first, then lpj. Enter the new password in the log.
  4. Install an SSH key while password login still works: generate one in .ssh/ or pick one, install it, then select it under “SSH key” in Connection. Also add it to users/lpj/nixos.nix, servers disable password login after the rollout.
